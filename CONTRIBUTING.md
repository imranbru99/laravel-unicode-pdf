# Contributing to laravel-unicode-pdf

Thank you for your interest in improving `laravel-unicode-pdf`!

## Code Standards
* Use strict types (`declare(strict_types=1);`).
* Adhere to PSR-12 and run Laravel Pint (`composer run fix`).
* Write unit or feature tests for all code contributions.

## Running the Test Suite
```bash
composer test
```

## Static Analysis
```bash
composer run analyse
```
