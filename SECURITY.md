# Security Policy

## Supported versions

Security fixes are provided for the latest released major version of `imrandevbd/laravel-unicode-pdf`.

## Reporting a vulnerability

Please do not open a public GitHub issue for security problems.

Email the maintainer at me@imrandev.bd with:

- A description of the issue
- Steps to reproduce
- Impact (for example SSRF, path traversal, or header injection)

You will receive a response as soon as possible. Please allow time for a fix before any public disclosure.
